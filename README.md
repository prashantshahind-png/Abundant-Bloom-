# Abundant Bloom

A mobile-friendly shop management app for sales, expenses, Udhaar, inventory, staff access, and reports.

## Setup

1. Create the tables in Supabase using `supabase-schema.sql`.
2. Enable Google authentication in Supabase.
3. Add the app URL and Supabase callback URL to Google OAuth settings.
4. The public publishable key is already configured in `app.js`; never add secret/service-role keys to this repository.
